Installing

macOS. The app is not notarised. If macOS reports that Klausel is damaged, move it to Applications and run xattr -cr /Applications/Klausel.app once.

Windows. The installer is not signed. When SmartScreen stops it, choose More info and then Run anyway.

Linux. Install with sudo apt install ./Klausel-linux-x86_64.deb, or the ARM64 package on ARM machines.
